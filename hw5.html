01 / Compare seasonal shares

A different seasonal mix in each state

The 12 states with the most known-season reports. Each row totals 100% for the selected report class, apart from rounding.

Loading seasonal heatmap…

Try it: change “Report class” below the chart to Class A or Class B. Hover a cell for the report count, percentage, and current state total. Restore All classes to reset. An em dash means the selected class has no reports in that state.

This heatmap visualizes how each state's reports are distributed across the four recorded seasons. The horizontal axis encodes season as an ordered category (ordinal), and the vertical axis encodes state as a nominal category. A sequential blue color scale encodes the quantitative within-state share: darker blue means a larger fraction of that state's reports, while percentage labels improve exact comparison. The fixed 0–100% domain keeps colors comparable across class selections. In Python, I trimmed category whitespace, excluded unknown seasons, checked unique report IDs, grouped records by state, season, and class, and filled absent combinations with zero counts. I selected and ranked the top 12 states by their total retained reports, breaking ties alphabetically; this state list stays fixed when the class changes. Vega-Lite filters the grouped data by class, sums counts by state and season, then divides by each state's selected-class total. This normalization compares seasonal composition without letting high-volume states dominate.

02 / Inspect report counts

Summer leads nationally. Does it lead locally?

Seasonal totals, stacked by report class. Choose a state to reveal its own pattern.

Loading seasonal bar chart…

Try it: select Illinois in “State” below the chart. Fall has 84 reports, compared with 68 in summer. Restore All states for the national view. Hover a colored segment to inspect its count.

This stacked bar chart shows the number of reports in each season and how each total is divided among Class A, Class B, and Class C. Season is ordinal on the horizontal axis, report count is quantitative on the vertical axis, and report class is nominal in color. The zero baseline makes stacked bar height proportional to the total count. Blue, orange, and purple provide distinct categorical colors without suggesting a numerical ranking among classes; unlike the heatmap, color identifies a class rather than an amount. The chart uses the same cleaned, zero-filled state × season × class count table produced in Python for Plot 1. Vega-Lite filters by the selected state and sums counts across states when All states is selected. I did not sample records, impute weather values, or derive seasons from incomplete dates. The y-axis rescales for each state, so tick labels and tooltips should guide comparisons between selections.

How the interactions help

The heatmap's class dropdown recalculates both counts and within-state percentages, letting readers test whether the seasonal pattern persists within a particular report class. The bar chart's state dropdown filters the plotted data, making local patterns visible even when they differ from the national mix. These data filters go beyond pan and zoom. The controls act independently, and hover tooltips supply exact values without crowding the charts.

Reading the results

Patterns in reporting, with limits

Across all retained reports, summer accounts for 1,765 records, followed by fall (1,413), spring (767), and winter (711). Illinois differs: fall exceeds summer. The heatmap reveals these differences in composition, while the bar chart preserves the scale of reporting.

The source has 4,747 rows; 91 have an Unknown season and are excluded from both charts. The supplied season labels are used directly. Reporting effort, outdoor activity, archive coverage, and other unmeasured factors can affect the counts. These charts do not establish seasonal behavior in an actual animal population. Class labels are retained as categories; see the BFRO classification definitions.
